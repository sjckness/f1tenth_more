## Can the bench avoid archiving in future?
Not selectively: the logger (`mission_logger_node`) records every mission that reaches LOADED and
finalizes it on abort/complete; it has no per-mission skip parameter. Whole-stack options, each
needing a stack restart, one line in `~/.config/f1tenth_car/stack_args`:
* `enable_mission_logger:=false`: no recordings at all (also none of real runs);
* `mission_logger_runs_dir:=/scratch/fabiocar/bench_archive`: record, but into a throwaway directory
  while benchmarking (remove the line afterwards).
A selective switch (for example skipping a plan id prefix) would be a change to the mission logger,
which is out of scope here.

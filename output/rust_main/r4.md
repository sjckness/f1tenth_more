## 1. The crate

- `src/rust/f1tenth_hard_stop_rs`: ament_cargo package (Cargo.toml, package.xml, build.rs +
  build_info.rs as in R0), rclrs `=0.7.0`, message crates builtin_interfaces/std_msgs/sensor_msgs/
  ackermann_msgs (+ example_interfaces/test_msgs for ros2_rust#557, + `<build_depend>
  f1tenth_messages` for the workspace resolution), serde_json with `float_roundtrip`. Lints:
  `unsafe_code = "forbid"`, unwrap/expect/panic denied. Added to `src/rust/Cargo.toml`.
- `decision.rs` keeps the Python's arithmetic and evaluation order (bearing `angle_min + i*inc` in
  f64, `laser_x + r*cos(b)`, `0.0 + r*sin(b)`, validity `finite && >= range_min && <= range_max`,
  stable nearest-first sort, `max(int(debounce), 1)`, `now - last >= clear_s`, lane freshness
  `now - t <= timeout`). Scan ranges are generic over f32 (the message) and f64 (the tests' lists).
- `core.rs` reads the clock exactly where the Python reads `self._now()`, the same number of times
  (the replay compares the count). Time is the node clock: system time on the car, /clock under
  use_sim_time. The republish timer is created with `TimerOptions::node_time()` (rclpy timers run
  on the node clock; rclrs's default is the steady clock), so it pauses with a frozen /clock like
  the Python's.
- `pyfmt.rs` reproduces CPython's `round`, `repr`, `json.dumps`, `format` and `math.degrees`, so the
  `/safety/hard_stop` JSON and every log line are byte-identical to the Python's. Rust's shortest
  float form differs from CPython on exact ties between two shortest candidates (found by the
  sweep); fixed and unit-tested.
- main.rs keeps the 15 parameter handles alive: rclrs 0.7 undeclares a parameter when its handle is
  dropped, which would hide them from `ros2 param` (found here; the guard and costmap nodes have the
  same pattern, recorded for the coordinator).
- Startup refusals (config.rs `validate`, all errors joined): footprint values missing,
  `hard_stop_republish_hz` not giving a positive ns period. Logs: build info, the Python's startup
  line byte for byte, then the clock kind, the republish period and the subscriptions.

# Area: platform (Piattaforma: porting, container, prestazioni)

Porting Humble -> Jazzy (Thor, Orin), container dell'auto, porting Rust/C, CPU e prestazioni, DDS e bringup.

## 1. Stato attuale

> Jazzy in parità con Humble su Thor e linus; container Orin pronto ma P9-P12 in attesa; CPU dominata da glue Python.

- Parità Jazzy (Thor, offline): `slam_pose_relay`, semantic layer e solver MPC bit-identici; `ekf_global` RMS 0.0044 m; `costmap_boundary` errore mediano 0.5 gradi; run di confronto sull'Orin mai eseguiti.
- Bringup Jazzy: 32 nodi in 7.5 s; il profilo Fast DDS con lease 5 s porta l'isolamento da 8/30 a 1/60 bringup.
- main-jazzy su linus: 5226/5373 test, 0 nuovi fallimenti; fase 2 sul Thor non fatta.
- Container Jazzy sull'Orin (e257b03, 9.84 GB): 63 nodi, CPU 17.5 % contro 24.8 % nativo; parità, wheels-up e cutover (P9-P12) in attesa.
- Rust: porting bit-identici su x86 (solver MPC p95 10.4 -> 2.0 ms); su aarch64 il gate a 1e-9 fallisce, gli switch restano `py`.
- CPU: stack replayato 3.75 core su linus, `mpc_corr` 69 % di un core di cui l'82 % è assemblaggio Python del QP; sull'Orin il core 5 era saturo (wall tracker + front wall).
- `extract_lines` in C: 22.5 volte più veloce, equivalente su 2292 scan.

## 2. Decisioni prese

- Un solo profilo Fast DDS (lease 5 s) per ogni partecipante ([2026-10-05_fix-batch-5](2026-10-05_fix-batch-5/report.md))
- Clean rebuild dei pacchetti C++ dopo ogni upgrade `ros-jazzy-*` ([2026-10-05_jazzy-phase5-bringup](2026-10-05_jazzy-phase5-bringup/report.md))
- Immagine Orin "opzione C" (Ubuntu 24.04 + apt Jazzy del Thor + CUDA 12.9) ([2026-10-12_phase5d-orin-jazzy-image](2026-10-12_phase5d-orin-jazzy-image/report.md))
- `wall_extract_backend` C, decimazione del tracker 4, cap per ruolo ([2026-10-16_cpu-h1-h5](2026-10-16_cpu-h1-h5/report.md))
- BT a 10 Hz, e-stop LiDAR a eventi, `costmap_boundary` 10 Hz ([2026-10-16_cpu-cleanup](2026-10-16_cpu-cleanup/report.md))
- Switch Rust `*_impl` default `py` finché manca l'analisi di tolleranza aarch64 ([2026-10-24_orin-container](2026-10-24_orin-container/report.md))
- Fase 2 delle ottimizzazioni ferma in attesa di via libera ([2026-11-11_perf-baseline](2026-11-11_perf-baseline/report.md))

- Parità Rust su aarch64 (tolleranze) e replay bag sull'Orin.

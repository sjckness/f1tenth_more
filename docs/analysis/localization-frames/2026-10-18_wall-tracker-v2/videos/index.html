How to read the videos

  • Left half of a side-by-side is V1, right half V2; each frame carries its own [variant] label, so a single file is never ambiguous.
  • Camera view: the class mask tinted over the photo, the YOLO instance outlines, the scan projected and coloured by its column status, and every confirmed wall as a rectangle labelled id role distance source state. The bar under it carries the contract and the front distance.
  • Top-down: the scan, the walls with their ids, the car, the objects, the strip and the true nearest return in it.
  • The camera video covers the moving window only; the top-down covers the whole run.

================================================================================
 CAVEATS
================================================================================

1. transport_drivers + zed-ros2-interfaces are embedded repos, NOT registered
   submodules. `git submodule update --init --recursive` only fetches the 4
   registered ones. Add real .gitmodules entries if you want reproducible clones.

2. ZED version alignment (watch for build-time mismatches):
     - zed_ros2_wrapper      = humble-v4.2.5  (4.2.x API)
     - Docker images install   ZED SDK 5.2    (gpu: 5.2 base / jetson: 5.2.3 L4T38.4)
     - zed-ros2-interfaces   = tag 5.3.0      (SDK-5.3 message set)
   The 5.3 interfaces shadow apt ros-humble-zed-msgs. If the build fails on
   zed_interfaces::msg::* members, move zed-ros2-interfaces to a 4.2.x-/5.2-
   compatible tag. Do NOT bump the SDK in the Dockerfiles to "fix" it — that
   re-introduces the wrapper-vs-SDK API mismatch.
